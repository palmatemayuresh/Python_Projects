# Password Strength Checker

Made a simple password strength checker using Python.

The program takes a password from the user and checks its length, uppercase letters, lowercase letters, numbers and special characters. Based on these things, it tells whether the password is weak, medium or strong.

## What I learned

- How to use `for` loops to go through each character in a password.
- Using `if`, `elif` and `else` for conditions.
- Using `.isupper()` and `.islower()` to identify letters.
- Using `.isdigit()` to check numbers.
- Using `.isalnum()` to identify special characters.
- Using counters with `+= 1`.
- Combining multiple conditions using `and`.
- Debugging mistakes in my code.

## How to use

1. Run `password_checker.py`.
2. Enter a password when asked.
3. The program will display the password length and character counts.
4. It will then show whether the password is weak, medium or strong.
